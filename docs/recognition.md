# 离线象棋识别

[文档目录](README.md) · [外部接管](external-takeover.md) · [性能](performance.md)

## v1.0.3 的识别流程

1. 定位棋盘的 9 列、10 行交点。仍可在同一核对窗口用两点重新定位；网格对齐与棋子识别是两个步骤。
2. 按棋盘朝向裁切、归一化，由随包的象棋专用模型一次判断 90 个位置的棋子类型、阵营或空格。自动朝向使用将帅的位置核验，必要时再尝试旋转后的方向。
3. 核查置信度、将帅、子数上限及棋子可占位置。超额时标记所有冲突棋子，不通过删除某一枚来凑成合法局面。
4. 少量位置仍不确定时，中文 PP-OCRv5 只补查这些位置，自动补查预算为 800 ms。证据冲突或超时则保留人工核对；不把低置信度棋子直接当空格。
5. 连接后继续用增量观测、已确认样本及合法续着同步棋局；恢复和落子前核验调用完整识别。核验期间目标画面再次变化，就先处理新帧，再决定是否发送落子。

识别窗口中的 **文字补识** 可主动执行完整中文 OCR，耗时通常比默认识别长。正常连接不需要先点击它，也不需要下载对应皮肤的识别包。标准开局按钮、连续摆子、移动、擦除和撤销仍保留在核对窗口。

模型、预处理和判断条件对所有截图统一使用，没有为这次提供的皮肤训练、建立新模板或编写分支。会话样本是用户确认当前棋盘后自动学习的视觉参考，用于后续增量追踪；不能取代落子前的独立局面核验。

## 模型比较

2026-10-06，Apple M3 / 24 GB、CPU 2 个推理线程，本地离线运行。样本共 20 个输入：16 张不同来源图像及其中 4 张的半分辨率副本，共 1,800 个交点、582 个有子位置。使用固定网格和已知朝向。OCR 两种规格均使用客户端相同的多视图字符识别流程；专用模型使用上游的标准朝向和预处理。

| 方法 | 有子位置类型及阵营正确率 | 全部 90 格正确的图像 | 预热后整盘中位耗时 |
| --- | ---: | ---: | ---: |
| PP-OCRv5 mobile 中文 OCR | 89.86% | 8 / 20 | 8.84 秒 |
| PP-OCRv5 server 中文 OCR | 91.07% | 8 / 20 | 28.17 秒 |
| nano_v3-0319 象棋专用模型 | 99.83% | 19 / 20 | 约 182 ms |

专用模型全部交点正确率为 99.94%。9 张报告过问题的原图或棋盘裁图均整盘正确。相同样本改用现有自动定位后，专用模型仍为 19 / 20；这不包含任意桌面多窗口定位和自动朝向的准确率。

剩余错误来自一张带标定点覆盖的金色棋盘编辑器截图：黑车被判成红车。客户端会通过置信度和数量冲突保留核对，不能因为局面“像开局”就直接覆盖为标准开局。

发布版 C# 完整识别入口在相同 20 个输入上的一次回归：19 张 FEN 完整正确，18 张通过全部自动核验，自动放行的局面中没有错误。金色标定覆盖图保留冲突，Windows 网页截图另保留一枚低置信度黑车待核对。预热后入口耗时中位约 177 ms，范围 137–968 ms，包含必要的局部 OCR；未计截图和定位，也不是冷启动时间。

以上是模型比较，不是整条接管链路的帧率。发布版还增加置信度核验和必要的局部 OCR；自动方向反转可能需要第二次推理。截图、定位、动画等待、引擎搜索和目标窗口响应另计。

## 回归测试与范围

`BoardClassifierTests` 使用可复现的网格、FEN 和真实图片，清单位于 `PaddiChess.Tests/Fixtures/recognition-cases.json`。检查每一个已放行的位置，重点覆盖：

- 车吃车前后及后续马步、银色棋盘、红上黑下、网页棋盘。
- 初始朝向设置错误、截图行尾填充、空白和不透明遮挡。
- 子数超额、非法位置、取消后的推理资源释放。
- 中文补识只处理请求的位置。

接管调度测试另外使用人工绘制的英文字母棋子及独立测试识别器，以验证时间、事件与输入顺序；它们不计入真实模型准确率。

这些是有限回归样本，部分已用于已有识别流程的开发，也包括重复缩放图，不能代表独立大样本评测或未见皮肤的 99.99% 保证。未知字体、低分辨率、动画、遮挡和错误网格仍可能导致不确定或误识别。Windows 包使用相同模型和预处理，但上述耗时来自 macOS，不能作为 Windows 实测值。

## 本地运行与许可

无需联网识别，也不把棋盘截图上传到 API 服务。模型只加载一次，在后台任务上使用 ONNX Runtime CPU 推理；取消可以中止当前推理。运行时校验模型 SHA-256。若专用模型文件损坏或不可加载，会尝试完整中文 OCR，使核对窗口仍可使用，此时会明显变慢；请重新安装完整发行包。
