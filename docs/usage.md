# 快速上手

[文档目录](README.md) · [外部接管](external-takeover.md)

## 五个工作区

| 页面 | 主要内容 |
| --- | --- |
| 对弈 | 棋盘、红黑双方执棋方式、棋谱、注释、分析和模型说明 |
| 外部接管 | 目标窗口、同步、轮次、朝向、接管方、开始／停止、历史 |
| 棋盘与搜索 | 显示、动画、音效、搜索预算、测速与识别设置 |
| 引擎插件 | 引擎版本、程序、NNUE、能力检测和规则选项 |
| API 服务 | 服务地址、临时 Key、模型目录、启用模型与连接测试 |

切换工作区保留棋局和已配置选项。分栏可调整宽度；外部工作台把棋谱和分析并排放置，核心控制无需多级菜单。

## 本地对弈

默认红黑双方均为玩家。点击棋子，再点击合法目标走棋；也可分别切换为引擎、大模型，让人机或不同控制方式对弈。

引擎使用当前默认插件。模型需要先在“API 服务”配置并启用，再为对应执棋方选择服务、模型与思考等级。API 用量和授权由服务提供方决定，流程见[引擎与模型](engines-and-models.md)。

“新局”创建标准棋盘。翻转只改变显示方向，不交换棋子颜色或行棋方。棋盘默认黑上红下，白点标记上一手起点。

## 分析与评分

普通对弈可以自动显示评分；开启分析模式或引擎执棋时可显示候选与应手路线。整数分是引擎评价，不是胜率百分比；将杀采用“红方杀 N / 黑方杀 N”一类标签。

终局保留结果、棋谱和最后一手之前的搜索信息。切回历史手数可查看当时记录。提高线程、Hash 或名义深度不保证按比例更强，见[性能说明](performance.md)。

## 新建自定义棋谱

1. 点击“自定义棋谱”，进入图形摆棋。
2. 选择棋子，再点棋盘放置；可连续放置，满额选项禁用。
3. 点击场上棋子后再点目标位置可移动或替换；使用擦除、清空和撤销编辑修正。
4. 核对朝向和先手，确认初始局面后开始记录。

也可导入 FEN。FEN 保存当前布局与行棋方，不等于完整历史：从中局 FEN 开始，程序不知道此前发生过哪些重复或长将长捉。

## 保存、导入与复盘

“保存棋谱”导出 `.paddi.json`，包括初始 FEN、UCI 着法、当前浏览手数、注释、已有评分和模型可见说明。导入会先验证完整续接，失败时保留当前棋局。

点击棋谱中的“开始”或某一步，或使用上一步／下一步复盘。从过去手数继续走棋会形成新的续着，原来该位置之后的着法和不再对应的说明随新分支更新；要保留多个版本，请分别保存。

实时接管期间，历史浏览和修改受到限制，避免屏幕局面与计算局面分离。可打开“接管记录”查看事件；断开后再加载整份棋谱。

## 模型说明

思考面板只显示服务实际返回的可见思考或说明，不构造未提供的内部推理。已完成着法的说明关联棋谱手数，可复盘回看。

双模型本地对局支持提和与接受／拒绝。外部接管不会代点目标游戏的提和按钮。

## 外部局面的标准开局入口

接管控制区“标准开局”暂停自动输出，按当前朝向生成 32 子、红方先行，并打开局面校对窗口。它是编辑起点，不重置目标游戏。目标已经走棋时，按截图修改棋子与轮次，或使用自动识别／重新同步。

采用局面后，核对实时棋盘，再明确点击开始接管。详细流程见[外部接管](external-takeover.md)。
