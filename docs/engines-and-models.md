# 引擎插件、原生规则与模型 API

[文档目录](README.md) · [性能设置](performance.md) · [数据与隐私](privacy-and-data.md)

## 默认引擎与 UCI 插件

随包引擎为 Pikafish 2026-09-25，配套 `pikafish.nnue`。程序通过 UCI 启动独立引擎进程；引擎执棋、分析与接管使用当前默认插件。

引擎与 NNUE 保留各自许可。NNUE 随附协议包含未经允许不得商用等限制，应用的 AGPL 许可不会替代该协议；见[来源说明](../Paddi象棋/Packaging/Engine-README.md)。

在“引擎插件”中：

1. 添加版本，指定适配本机系统／架构的 UCI 象棋引擎程序。
2. 按引擎要求选择 NNUE；留空时保留该引擎自身默认或内嵌权重，不自动套用随包权重。
3. 检测引擎，查看名称、声明的选项和允许值。
4. 保存独立设置，再设为默认。检测失败保留原默认。

支持 `.paddi-engine.json` 配置导入导出。配置不等于引擎程序；复制到另一台电脑后仍需核对程序和权重路径。移除插件条目不会删除原程序。

引擎是以当前用户权限运行的本机可执行程序，不是隔离运行的脚本格式。只添加来源可信且许可允许使用的引擎。实时接管中切换引擎前，先停止对应会话。

## 规则选项来自引擎声明

客户端解析 UCI 握手中的选项类型、范围与候选值，按检测结果生成设置，不向未声明的引擎强行发送某个版本的规则参数。

随包 0925 引擎声明的规则包括 `Repetition Rule`、`Draw Rule`、`Sixty Move Rule`、`Rule60MaxPly`、`Mate Threat Depth`。其中 `Repetition Rule` 默认 `AsianRule`，还包括 `ChineseRule`、`SkyRule`、`ComputerRule`、`YitianRule`、`AllowChase`、`NoJudgement`。其他插件的支持情况必须以实际检测为准。

搜索会提供起始 FEN 和完整已确认 UCI 历史，让引擎自身处理历史规则。客户端不采用“同一棋子将军固定几次就禁走”的简化替代。仅导入当前 FEN 时，接入之前的重复次数未知。

## 独立的 PaddiRules 组件

模型选招前，程序通过独立原生进程 `PaddiRules` / `PaddiRules.exe` 获取允许候选。它直接复用 Pikafish **2026-09-06** 源码的合法着法生成、走子和 `rule_judge`，不做 NNUE 评估或棋力搜索。

- 请求包含起始 FEN 与已确认历史。
- 候选分为 `allowed` 和 `excluded`。
- 只有原生裁判明确判定后续位置使走子方因规则输棋的着法才排除。
- 普通和棋循环或战术上较差的走法不因此被当作禁手。
- 规则组件失败时暂停，不绕过校验继续发送。

该组件固定为 0906 规则源码，**不随 0925 内置引擎或其他插件的规则选项切换**。低等级内置引擎选招也可能使用这份候选校验；外部插件则使用自己的搜索结果和已声明能力。目标游戏仍是外部实战的最终裁判。

来源、协议和适配范围见[原生组件说明](../Paddi象棋/Native/PikafishRules/SOURCE.md)。组件完整源码与许可随发布包保存在 `Native/PikafishRules-source.zip`；此 ZIP 对应规则组件，不是 0925 主引擎的完整对应源码。

## 多服务与模型配置

在“API 服务”添加服务名称、地址和本次运行使用的 API Key，获取模型列表，勾选需要启用的模型。服务没有列出某模型时，可以手动填写模型 ID；可填写不代表账户已被授予调用权限。

红方、黑方与外部接管可以选择不同服务及模型。修改地址、Key 或当前服务，会取消失效的模型目录请求；旧响应不得覆盖新服务的列表。

远程服务地址要求 HTTPS，本机地址可用 HTTP。示例地址应使用你自己的服务配置；项目文档不提供公共共享 Key，也不要求绑定某个私人中转服务。

应用使用兼容的聊天补全请求与模型目录接口，支持工具调用、结构化回复以及服务支持时的流式输出。接口外形兼容不保证每个模型都支持相同的工具、流式字段或思考等级。

## 思考等级、权限与错误

思考等级由用户明确选择。“自动”不发送等级；其他等级按配置发送 `reasoning_effort`。服务拒绝所选等级时会提示错误，客户端不会代替用户偷偷降低等级。

服务需要同时满足账户权限、模型可用性、余额／额度和参数支持。模型列表返回某个 ID、HTTP 请求成功或具有相同 API 格式，都不能保证某个高级模型或等级可调用。费用和限额由该服务计量。

若出现权限错误，检查 Key 所属账户和模型授权；若参数不支持，选择服务实际支持的等级／模型。不要把 Key、含鉴权的 URL 或完整请求头贴到公开 Issue。

## 选招与记录边界

请求包含当前 FEN、经原生规则过滤的合法 UCI 候选和必要的对局指令。优先使用工具调用；不支持时可以使用结构化回复。返回后再次检查所选着法、请求对应的棋局和当前状态，无效响应在有限重试后仍失败则暂停。

合法着法不等于高棋力着法。模型可能在允许候选中选出较差的一步，棋力取决于模型、预算和当前局面。外部模式不会通过模型响应代点目标游戏的提和按钮。

面板只展示服务返回的可见思考或说明，逐手保存，不生成或声称拥有模型未公开的内部推理。程序会掩去已知当前 Key 的直接回显，但分享自由文本说明前仍应自行检查其他个人信息。

Key 保存在进程内存，退出后需要重新输入；服务地址、模型目录、启用状态和选手偏好保存在本机。详细数据范围见[数据与隐私](privacy-and-data.md)。
