# 深蓝棋盘、银白棋子回归样本

这些图片来自用户在本次识别问题中提供的 JJ 象棋截图，用于验证棋盘定位、字形识别和朝向处理。棋盘美术及游戏内容的权利属于原权利人；样本不表示第三方参与或背书。

| 文件 | 保留范围与处理 |
| --- | --- |
| `jj-silver-blue-midgame.png` | 从故障截图中裁出左侧完整棋盘，770 × 850；未采用右侧已手动调整的编辑器网格 |
| `jj-silver-blue-opening-flipped.png` | 从后续原始 JJ 窗口截图裁出棋盘，774 × 840；红上黑下，保留真实棋子、浮雕和选择光圈 |
| `jj-silver-blue-full-window.png` | 保留原窗口 774 × 1460 尺寸、完整棋盘、上下背景和圆形工具栏；仅用纯色块遮住棋盘外顶部、底部两处头像 |

原始未遮挡的全窗图仅用于本机验证，不作为公开测试资源。公开样本不包含用户的 API 设置窗口、私人服务地址或电脑文件路径。

这些文件**仅是测试输入，不是生产识别模板**，未加入 `BuiltInBoardSkins`、应用资源或用户样式缓存。定位测试从完整窗口开始，不预先提供棋盘坐标；另有裁图测试隔离 OCR 与定位误差。测试还会在内存中缩放或反相，检查实现是否依赖固定尺寸和颜色。

主要使用位置：`BoardLocatorGeneralizationTests`、`SilverBoardRecognitionTests`。
